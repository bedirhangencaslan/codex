# Renames this fork must keep when a merge would otherwise revert them.
#
# The rename commit (f06d1e476) changed two different kinds of thing under one heading.
# Only one of them belongs here.
#
#   the product name      prose, comments, messages, anything a person reads.
#                         Reverting it costs nothing, so it is NOT listed here and the
#                         merge driver lets it follow upstream. That is deliberate: the
#                         name is what made ~90% of the 2026-09-20 merge's 256 conflicts,
#                         and letting it follow upstream is what makes them stop.
#
#   the runtime identity  names the running program reads: an environment variable it
#                         looks up, a directory it opens, an enum variant or class the
#                         compiler resolves. Reverting one of these does not produce a
#                         differently-worded message, it produces a program that looks in
#                         the wrong place or does not build.
#
# Format, one per line:   <upstream form> => <our form> [| <path prefix>]
# The optional path prefix limits the rule to files under it.
# Lines starting with `#` are comments. Order matters: longest match first.
#
# Verify with: python scripts/merge/verify-map.py
# That script reads the tree and fails if a load-bearing rename is missing here.

# --- environment and on-disk layout -----------------------------------------

# `protocol/src/permissions.rs` keeps the sandbox out of.
.codex => .suffice
