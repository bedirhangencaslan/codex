# Context Filters

## Call Chain

The normal request path is:

1. `run_turn` calls `freeze_reasoning_retention` (`seed-rs/core/src/session/turn.rs:374`), then `prompt_input_for_step` (`seed-rs/core/src/session/turn.rs:378`).
2. `run_sampling_request` reuses the first input for its first attempt, but rebuilds through `prompt_input_for_step` on retries (`seed-rs/core/src/session/turn.rs:1393-1398`).
3. `prompt_input_for_step` clones history and calls `for_prompt_measured` (`seed-rs/core/src/session/mod.rs:4055-4065`).
4. `for_prompt_annotated` runs, in order: turn-scoped drops, normalization, and the tool-output shrinker (`seed-rs/core/src/context_manager/history.rs:315-341`).
5. The resulting items go to `build_prompt` (`seed-rs/core/src/session/turn.rs:1406-1410`).

All prompt-time mutations are made to a cloned history, not the stored history. Only reasoning-retention verdicts are written back into stored history before this clone is made.

## Prompt-Time Filters

| Order | Filter | Gate |
|---|---|---|
| 1 | Drop finished invisible-turn items | `seed-rs/core/src/context_manager/history.rs:720`: metadata `invisible_turn` is `Some(owner)` and `belongs_to_active_turn(active_turn_id, owner)` is false. That helper is false unless both values are `Some` and equal (`history.rs:765-769`). |
| 2 | Drop finished reasoning | `history.rs:723-738`: item is `ResponseItem::Reasoning`; its `reasoning_turn` does not belong to the active turn; and `metadata.reasoning_retained != Some(true)`. Missing metadata, missing owner, or a `false` verdict causes the drop. |
| 3 | Ensure call outputs exist | `seed-rs/core/src/context_manager/normalize.rs:21-137`: inserts a synthetic `aborted` output after a function, tool-search, custom-tool, or local-shell call whose call ID has no matching output. |
| 4 | Remove orphan outputs | `normalize.rs:155-225`: removes function/custom-tool outputs with a call ID not present on any corresponding call. Tool-search outputs are removed only when `execution != "server"` and their call ID has no matching call. |
| 5 | Strip unsupported images | `normalize.rs:330-377`: runs only when `input_modalities` does not contain `InputModality::Image`; then replaces image content in messages/tool outputs and clears image-generation results. |
| 6 | Strip unsupported audio | `normalize.rs:381-420`: runs only when `input_modalities` does not contain `InputModality::Audio`; then replaces audio content with an unsupported-media marker. |
| 7 | Shrink completed tool output | `seed-rs/core/src/context_manager/tool_output.rs:130-180`: see the detailed gates below. |

The first two filters are invoked by `drop_completed_turn_scoped_items` (`history.rs:348-388`). Its first removal sets `report.prefix_break` with `get_or_insert(index)` at `history.rs:360`. Normalization runs at `history.rs:619-633`; the shrinker runs afterward at `history.rs:324-330`.

## Shrinker Gates

For each history item, the shrinker requires every condition below:

1. Its `tool_output_turn` metadata does not belong to the active turn (`history.rs:324-329`, `tool_output.rs:143`). Missing metadata counts as completed.
2. It is a `ResponseItem::FunctionCallOutput` (`tool_output.rs:146-151`).
3. Its output success is exactly `Some(true)` (`tool_output.rs:154`).
4. Its call ID is present in the IDs derived from calls whose parsed command is in the shrinkable allowlist (`tool_output.rs:138-141, 157-159, 183-198`). Chained/redirected shell lines and unrecognized commands are excluded (`tool_output.rs:201-272`).
5. Its body is text (`tool_output.rs:160-162`).
6. It has at least 45 lines: `KEEP_HEAD_LINES + KEEP_TAIL_LINES + 10` (`tool_output.rs:21-26, 286-290`).
7. `prefix_break` is `Some(index)` and the output's history index is greater than or equal to that value (`tool_output.rs:166-169`).

Only the final condition can refuse an otherwise shrinkable item because of global prompt-cache policy. When it does, the item is counted in `shrinkable_before_break` and left whole.

## Timing

The prompt-time pipeline can run in the middle of a user turn: `run_turn` loops, records tool output, and rebuilds each follow-up prompt. The first prompt-time filters can therefore remove older finished-turn items, normalize older history, or shrink outputs from earlier turns. They cannot shrink an output produced by the currently active turn because the completion closure excludes the active `tool_output_turn` owner (`history.rs:324-329`).

Reasoning retention is the exception. `run_turn` calls it before building the prompt (`turn.rs:372-374`), and the implementation writes a frozen metadata verdict (`seed-rs/core/src/reasoning_retention.rs:82-153`). It can run idempotently during the turn loop, but `is_undecided_completed_reasoning` excludes reasoning owned by the active turn (`reasoning_retention.rs:177-190`). Thus the decision for a given turn's reasoning is effectively made only after that turn ends, on the next turn/request cycle.

Record-time output truncation is adjacent but not part of `for_prompt_annotated`. It occurs when items are recorded (`seed-rs/core/src/session/mod.rs:3272`) and truncates only function/custom-tool outputs (`seed-rs/core/src/context_manager/history.rs:212-236`). A metadata fallback override becomes `TruncationPolicy::Tokens(...)`; otherwise the model policy is multiplied by 1.2 (`history.rs:230-235`). It can run as each tool finishes and can shorten output before the prompt-time shrinker ever sees it.

## Why the Shrinker Does Not Fire

The blocking value is `prefix_break == None`.

`ContextFilterReport` initializes `prefix_break` to `None` (`history.rs:688-694`). The only assignment path is inside `drop_completed_turn_scoped_items`: when `dropped_reason(...)` returns a reason, the current item index is inserted into `report.prefix_break` (`history.rs:358-360`). Therefore:

* no dropped invisible-turn item, and
* no dropped finished reasoning item

means `prefix_break` remains `None`. The shrinker then reaches the cache gate at `tool_output.rs:166` and fails it unconditionally because `None.is_some_and(...)` is false. The output is left whole and counted as `shrinkable_before_break`.

So the root cause is not the allowlist, output type, success flag, or 45-line threshold. Those gates can individually prevent shrinking a particular output. In an ordinary session with no invisible-item or reasoning drop, all otherwise eligible outputs fail the same final condition because the `prefix_break` value blocking them is `None`, computed only by the first turn-scoped drop at `history.rs:360`.
