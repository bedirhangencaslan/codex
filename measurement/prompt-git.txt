Import this Rust workspace into a fresh git repository, one commit per crate.

Run these steps in order, each as its own shell command:

1. `git init`
2. `git config user.email "ab@example.com"` and `git config user.name "AB"`
3. For each of these eight directories, in this order, stage that directory and
   commit it on its own:

     ansi-escape, app-server, apply-patch, arg0, backend-client, cli, core, tui

   Use `git add <dir>` then `git commit -m "Import <dir>"` for each. Run the add
   and the commit as separate commands. Do not pass `--quiet`, do not redirect
   or pipe the output, and do not chain commands with `&&` or `;` — each git
   invocation must be its own shell call so its full output is returned.
4. `git add -A` then `git commit -m "Import the rest"`.

STOP CONDITION. After the last commit, run `git rev-list --count HEAD` and print
`CHECKPOINT REACHED: <n> commits`. Then stop. Do not inspect the repository
further, do not read any source file, and do not write any file.
